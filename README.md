# LearnHubAI

LearnHubAI is a Learning Management System (LMS) designed to provide an online learning platform where students can discover courses, enroll in courses, access learning materials, and track their learning progress.

The application supports three major roles:

- Student
- Instructor
- Admin

## Features

### Student

- User registration and login
- Account activation
- Browse and search courses
- View course details
- Enroll in courses
- Purchase courses through the payment system
- Access purchased courses
- Add courses to wishlist
- Track learning progress
- Manage profile information

### Instructor

- Instructor dashboard
- Manage courses
- Create and update courses
- Manage course content
- View enrolled students
- Track course information

### Admin

- Admin dashboard
- Manage users
- Manage instructors
- Manage courses
- Manage enrollments
- Manage orders
- Manage refunds
- View platform statistics

## Project Setup

### 1. Clone the repository

```bash
git clone https://github.com/sk2003-sk/LearnHubAI.git
```

### 2. Navigate to the project

```bash
cd LearnHubAI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file and configure the environment variables required by the application.

Refer to `.env.example` when available.

### 5. Start the development server

```bash
npm run dev
```

### 6. Create production build

```bash
npm run build
```
