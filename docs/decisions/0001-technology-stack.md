# ADR 0001 - Technology Stack

## Status

Accepted - Existing project technology choices.

## Context

LearnHubAI requires a frontend architecture that supports reusable components, dynamic interfaces, API integration, routing, authentication, and responsive design.

## Technology Decisions

### React

Used to build the user interface through reusable components.

### Vite

Used as the frontend development server and build tool.

### JavaScript

Used for application logic and component development.

### Tailwind CSS

Used for utility-first styling and responsive layouts.

### React Router DOM

Used for client-side navigation and route protection.

### Axios

Used for communicating with backend APIs.

### Git and GitHub

Used for version control and source-code management.

## Benefits

- Component reusability.
- Organized development.
- Responsive styling.
- Efficient frontend development.
- Centralized API communication.
- Maintainable routing.

## Decision

Continue using the existing technology stack unless a technical requirement justifies a change.

## Important

This document records the confirmed core stack. Additional libraries must be documented after verifying package.json.
